# OpenClaw Setup Guide — Site

Next.js 15 (App Router) + MDX documentation site for the OpenClaw public setup guide.

## Development

```bash
npm run dev        # start dev server on :3000
npm run build      # generate static export to out/
npx serve out      # serve the static build locally
```

## Search

Search is powered by **flexsearch** (pagefind was the first choice but fails on Pi 5 due to a jemalloc/16KB-page-size incompatibility with ARM64).

**How it works:**
1. `scripts/build-search-index.mjs` runs as a `prebuild` step and reads every MDX file from `content/guide/` and `content/appendix/`, strips markdown syntax, and writes `public/search-index.json` (12 documents, ~1 KB gzipped).
2. The static export copies `public/search-index.json` to `out/search-index.json`, so it's served alongside the site.
3. `src/components/site-search.tsx` loads flexsearch on first open (Cmd/Ctrl+K), fetches `/search-index.json`, builds an in-memory index, and queries it on each keystroke. Results link directly to the chapter page.

**To rebuild the index after editing content:** `npm run build` (runs prebuild automatically), or `node scripts/build-search-index.mjs` standalone.

## Table of Contents (right rail)

`src/components/page-toc.tsx` is a client component that:
- On mount, queries `article h2[id]` and `article h3[id]` from the rendered MDX (ids are injected at build time by `rehype-slug`).
- Uses `IntersectionObserver` with `rootMargin: '-80px 0px -60% 0px'` to track which heading is currently scrolled into the upper portion of the viewport, and highlights it in sky-500.
- Heading anchor links (the `#` that appears on hover) are generated by `rehype-autolink-headings`. Clicking one copies the section URL to the clipboard via the Clipboard API and navigates to the anchor.
- The TOC rail is hidden below `lg` breakpoint (1024px).

## Prev/Next navigation

`src/components/prev-next-nav.tsx` renders at the bottom of every doc page via `DocLayout`. It derives prev/next from a hardcoded reading-order array: Introduction → Ch. 1 → Ch. 2 → Ch. 3 → Ch. 4 → Ch. 5. Appendix pages are not included in this sequence.
